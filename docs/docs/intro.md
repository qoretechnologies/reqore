# Reqore

Reqore is a highly theme-able and modular UI library for React. This site is generated by Docusaurus and the API reference is generated from the TypeScript source via TypeDoc.

## Why Docusaurus?

- Fast local iteration with a live-reload dev server.
- Versionable markdown docs that sit next to your code.
- API documentation generated straight from the codebase.

## Documentation structure

- **Guides**: Human-written docs explaining how to use the library.
- **API**: Auto-generated from `src/index.tsx` and referenced types.
