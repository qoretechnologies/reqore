# ReQore Components

| Component | Description |
| --- | --- |
| **ReqoreAccordion** | Expandable/collapsible panels that can display multiple items with optional icons, badges, and callbacks for toggling. |
| **ReqoreBreadcrumbs** | Navigation component displaying hierarchical breadcrumb trails with responsive collapse and optional tab support. |
| **ReqoreButton** | Primary action button with support for icons, badges, loading states, effects, multiple style variants (minimal, flat, transparent), an optional `raised` prop that adds a subtle 3D inset highlight when paired with `flat`, and an optional `radiusSize` (`TSizes`) that decouples corner roundness from `size` using the pronounced `RADIUS_FROM_RADIUS_SIZE` scale. |
| **ReqoreCallout** | Inline message surface for inline notices, warnings, and confirmations. Supports a leading icon, optional `label` + `description` (or freeform `children`), badge (TReqoreBadge), accent strip (left/top; `accentSize` takes px or a `TSizes` name — `'normal'` = the 5px default), close button (`onClose` + `closeButtonProps`), and the standard prop set: intent (info/success/warning/danger; controls accent + border + icon colour), size, flat (border on `false`), rounded, `radiusSize` (`TSizes` — overrides the `size`-derived radius using the pronounced `RADIUS_FROM_RADIUS_SIZE` scale), fluid, fixed, transparent, raised (subtle 3D inset highlight when paired with `flat`), customTheme, tooltip, disabled, effect / labelEffect / descriptionEffect / contentEffect, `padded` (`true` \| `false` \| `'horizontal'` \| `'vertical'` — default `true`; the side adjacent to the accent strip still reserves room for it), `paddingSize` (`TSizes` — defaults to `size`), and click handlers. |
| **ReqoreCheckbox** | Toggle control that can render as a standard checkbox or switch component with customizable icons and text labels. |
| **ReqoreCollapsibleContent** | Height-clipping "show more" disclosure for long content. Content taller than `maxCollapsedHeight` (default `300`px) is clipped behind a gradient fade with a "Show more" button; expanding shows it in full with a "Show less" button, while short content renders whole with no fade. Distinct from `ReqorePanel`/`ReqoreAccordion`, which fully hide/show a labelled section — this previews overflowing content in place. The fade is the surface: `intent` tints it (danger fades into red, success into green, etc.) and `customTheme.main` sets the base background color the gradient fades into — set it to match the parent's background for a seamless blend. Reveal/collapse buttons get a default `backgroundBlur` effect so they stay legible over the faded content. Props: `maxCollapsedHeight`, `defaultExpanded`, `revealOn` (`'always'` \| `'hover'`, default `'always'`; `'hover'` hides the button until hover/focus for an ambient look — gated on hover capability, so on touch the button stays visible, and while hidden it is `pointer-events: none` so it can never fire as an invisible target), `buttonAlign` (`'left'` \| `'center'` \| `'right'`, default `'center'`), `buttonFluid` (stretches the reveal button to the overlay width), `showMoreLabel` / `showLessLabel`, `showMoreIcon` / `showLessIcon`, `buttonProps` (forwarded to both buttons), plus the standard prop set: intent (tints the fade and buttons), size (scales the fade height and the buttons), fluid, transparent (drops the fade gradient, keeps the affordance), disabled (dims the surface, short-circuits handlers), customTheme, effect, tooltip. The `ResizeObserver`-backed measurement degrades gracefully where the API is unavailable. |
| **ReqoreCollection** | Grid/list view component for displaying arrays of items with filtering, sorting, zoom, and pagination capabilities. |
| **ReqoreColumns** | Layout component using CSS Grid to arrange content into responsive columns with customizable gaps and alignment. |
| **ReqoreComment** | Single comment display component with optional icon/image, title, detail text, and action buttons. |
| **ReqoreCommentFeed** | Container component for displaying a vertical list of comments with customizable spacing between items. |
| **ReqoreContent** | Base content wrapper providing theme support and scroll handling for page content areas. |
| **ReqoreControlGroup** | Flexible group component for organizing child elements with support for stacking, spacing, responsiveness, and overflow handling. |
| **ReqoreControlGroupItem** | A neutral slot that makes several elements count as ONE child of a `ReqoreControlGroup`. A control group sizes each child individually and React fragments are transparent in the DOM, so a component rendering `<>…</>` into a group silently becomes N competing flex items — and where the leading element is full-width and cannot shrink, the rest are pushed outside the container. Wrapping them in this item restores the intent. It is deliberately NOT a nested control group: it adds **no gap by default** (pass `gapSize` to opt in), because standing in for a single child means it must not inject spacing the wrapped elements did not already have. Props: `horizontal` (lay its own children in a row instead of a column), `gapSize` (`TSizes`), `fluid` / `fixed` (mirror the group's own child sizing, so the slot occupies exactly the space the child it replaces would have), plus `size`. The group's cloned child props (`minimal`, `flat`, `fill`, `stack`, `spaceBetween`, `intent`, `customTheme`) are accepted so the item is a valid group child and dropped before the DOM, but intentionally do **not** cascade to its children — re-applying them is exactly what would stop it standing in transparently. `min-width: 0` so an over-wide child shrinks instead of overflowing. |
| **ReqoreDatePicker** | Date and time picker with calendar interface, time selection, and support for various date formats and granularity options. |
| **ReqoreDataView** | Type-aware, collapsible renderer for structured records, arrays, and scalar values. Keys and compact scalar chips use consistent monospace data styling; multiline strings preserve whitespace in bounded, scrollable data blocks so large text payloads remain readable. Supports typed envelopes, embedded-data parsing, inline scalar arrays, item interaction, and controlled editing. |
| **ReqoreDescriptionList** | Read-only `<dl>`-style key/value list rendered inside a `ReqorePanel`. Built for "operator reads four labelled values top-to-bottom" surfaces (drawer lifecycle blocks, metadata strips) — distinct from `ReqoreKeyValueTable`, which is the searchable / sortable / exportable `ReqoreTable`-backed alternative. Accepts `items: { key, label?, content, intent?, uppercaseLabel? }[]`, `labelWidth`, `uppercaseLabels` (default `true` — labels read as eyebrow chips), `separatorOpacity` (default `0.06`), plus the full `IReqorePanelProps` surface forwarded to the wrapping panel: `label`, `icon`, `badge`, `flat`, `raised`, `minimal`, `rounded`, `transparent`, `intent`, `size`, `customTheme`, `effect`, `contentEffect`, `tooltip`, `disabled`. Every row reserves a 12px left intent-strip gutter so rows stay flush-aligned whether or not they carry an intent. Pass `transparent flat` (or `minimal flat`) when nesting inside an already-padded surface. |
| **ReqoreDrawer** | Sliding panel that can be positioned on any edge of the screen, with support for resizing, hiding, and optional backdrop. |
| **ReqoreDropdown** | Button-triggered dropdown menu supporting filtering, nested items, multi-select, and keyboard navigation. Its forwarded ref resolves to the rendered trigger element, allowing form engines to focus or measure the actual control without React ref warnings. `scrollToSelected` centres the selected item vertically on open; the scroll is smooth unless `animations.popovers` is `false` or the OS prefers reduced motion, in which case it jumps straight there (which is also what makes it deterministic for snapshot tests). |
| **ReqoreEffect** | Styled component providing visual effects like gradients, glows, filters, and text decorations. `effect.gradient` accepts either a single gradient object or an array of gradient objects — when an array is provided each entry is stacked as a CSS `background-image` layer in order (first entry on top); border-image / readable-text / animation behaviour is driven by the first gradient. Each gradient supports an optional radial `size` hint (e.g. `'ellipse 90% 120%'` or CSS sizing keywords) that is rendered between the shape and the position. Because `effect.gradient` may be a single object **or** an array, code that reads a gradient's config back out must not reach into `effect.gradient.colors` directly (it is `undefined` when an array was passed) — use the exported `getPrimaryGradient(effect.gradient)` for the top layer (or `normalizeGradients(effect.gradient)` for all layers). `effect.borderStyle` (`'solid'` \| `'dashed'` \| `'dotted'`) sets how a border is drawn on ANY effect-aware surface — a button, a tag, a panel, a callout, an entity row. A dashed or dotted border is the convention for an *add* affordance, where the control stands in for content that does not exist yet. Applied with `!important`, like `borderColor` and `fontFamily`, because components declare their border with the `border` SHORTHAND (`1px solid …`) which resets `border-style`. It sets the style only and never draws a border that was not there, so it is inert on a `flat` surface rather than wrong. |
| **ReqoreEmptyState** | Placeholder component displayed when content is unavailable, with optional icon, title, description, and action buttons. Optional `raised` adds a subtle 3D inset highlight to the placeholder surface. Accepts an optional `radiusSize` (`TSizes`) that is forwarded to the underlying panel and uses the pronounced `RADIUS_FROM_RADIUS_SIZE` scale. |
| **ReqoreEntityRow** | Compact row primitive for lists of items (e.g. automations, drafts, integrations) with a leading icon tile, label/description/metadata stack, badge support (TReqoreBadge), and right-side action buttons. Supports the standard prop set: intent (with tinted backgrounds), size, flat (border on `false`), rounded, fluid, transparent, raised (subtle 3D inset highlight when paired with `flat`), customTheme, tooltip, disabled, effect / labelEffect / descriptionEffect / metadataEffect, wrap (single-line ellipsis on `false`), `iconHasBackground` (defaults to `true` on opaque rows and `false` when `transparent={true}` so the tile does not fight the transparent surface; pass an explicit boolean to override), `padded` (`true` \| `false` \| `'horizontal'` \| `'vertical'` — default `true`; controls which axes receive outer padding), `paddingSize` (`TSizes` — defaults to `size`; scales padding independently from text/icon scale), and click handlers. **Row actions do not bubble into the row's own `onClick`** — every action button and overflow menu stops propagation, so an action and the row never both fire; an action that *should* also trigger the row calls the row's handler itself. On a container narrower than 480px (Reqore's mobile threshold) the actions wrap onto their own row under the label, aligned to the label rather than the icon — measured from the row's OWN container via `ResizeObserver` (stamped as `data-narrow`), not the viewport, so a narrow drawer on a wide screen wraps correctly. Deliberately lower than `ReqoreSeverityRow`'s 640px: that row carries a severity strip, a leading tag, a label AND a description before its actions, so it runs out of room sooner than this one does. |
| **ReqoreFeatureCard** | Highlight card for onboarding flows, feature spotlights, and product steps. Renders an optional marker (`'line'` \| `'number'` \| `'icon'` \| `'none'`; the `'icon'` variant pairs with the new `icon`, `iconColor`, and `iconProps` props to render a tinted icon tile above the label and is auto-selected when `icon` is set), label, description, and badge. Supports the standard prop set: intent (controls marker + border colour), size, flat (border on `false`), rounded, `radiusSize` (`TSizes` — overrides the `size`-derived radius using the pronounced `RADIUS_FROM_RADIUS_SIZE` scale), fluid, fixed, transparent, raised (subtle 3D inset highlight when paired with `flat`), customTheme, tooltip, disabled, interactive (auto-detected from `onClick`), effect / labelEffect / descriptionEffect / markerEffect, wrap (single-line ellipsis on `false`), `padded` (`true` \| `false` \| `'horizontal'` \| `'vertical'` — default `true`), and `paddingSize` (`TSizes` — defaults to `size`). |
| **ReqoreErrorBoundary** | React error boundary that catches errors and displays them with optional fallback UI and reset functionality. |
| **ReqoreFadeScroller** | Single-line horizontal scroller that fades whichever edge still has content out of view — for chip strips, tag rows, stat rails and any row of peers that would otherwise wrap into a ragged block on a narrow screen. Reach for this instead of `ReqoreControlGroup wrap` whenever wrapping would turn one row into N rows on a phone and push the page's real content below the fold; the fade is what makes the overflow discoverable, since a clipped row otherwise looks like a complete one. The gradients are overlay pseudo-elements on the wrapper (not inside the scrolling box, where they would scroll away) and are `pointer-events: none`, so they never swallow a click on the item beneath. The native scrollbar is hidden on purpose — it is thicker than a row of chips — and the row stays scrollable by wheel, trackpad, touch and keyboard. Props: `gapSize` (`TSizes`, default `normal`), `verticalAlign` (`'flex-start'` \| `'center'` \| `'flex-end'` \| `'stretch'`, default `'center'`), `rigid` (default `true` — children keep their natural width and overflow rather than squashing; pass `false` for a rail of self-sizing grow-tiles whose own `flex` should win), `fadeColor` (defaults to the resolved main background so the fade reads as a dissolve rather than a grey smudge), `fade` (default `true`), `dragToScroll` (default `false` — grab the row and pull it sideways; a mouse has no horizontal axis, so an overflowing row is otherwise reachable only by shift+wheel or a trackpad gesture. Selection is preserved rather than traded away: **Shift**+drag selects on a pointer device, and on touch the drag never engages so native panning and long-press-to-select both apply unchanged. A drag that actually moved the row swallows the click that follows it, so pulling past a clickable child does not activate it while a plain click still does; text inputs are excluded as drag origins. The `grab` cursor appears only while the row overflows, via a `reqore-fade-scroller-draggable` class toggled by the same measurement that drives the fades — drag state is carried by classes, not React state, so a drag never re-renders the row's children), plus `fluid` (default `true`; pass `false` when the row sits beside other content in a flex layout and should take only the width it needs), `intent` and `customTheme`. Edge state is recomputed on scroll, on resize (`ResizeObserver`, degrading gracefully where unavailable) and after every render, since children can change width without the scroller resizing. |
| **ReqoreExportModal** | Modal dialog for exporting data in multiple formats (CSV, JSON, YAML) with copy-to-clipboard functionality. |
| **ReqoreModalsWrapper** | Portal wrapper that renders all queued modals and dialogs from the global context. |
| **ReqoreHeading** | Typography component for headings (H1-H6) with theme support and text effects. |
| **ReqoreIcon** | Icon rendering component using RemixIcon set with size, color, animation, tooltip, and an optional contour-following `glow` (boolean / colour / `{ color, blur, opacity }`) rendered via `filter: drop-shadow`. The global `ReqoreUIProvider` option `glowingIcons: true` opts every font icon into glow mode by default; individual icons opt out with `glow={false}`. Image icons (`image=...`) are exempt from the app-wide default (a coloured halo around a logo reads as noise) but still honour an explicit `glow`. |
| **ReqoreIconPicker** | Picker for any icon from the RemixIcon set (~3000 icons). By default it is a button-triggered popover hosting a filterable icon grid; with `inline` it renders that same grid directly in the layout (no trigger button, no popover). The grid is virtualized with `react-window`'s `FixedSizeGrid` — only the cells in view are mounted, so the whole filtered set scrolls as one surface. By default the grid is fixed-width with uniform square cells and shrinks to fit its content (`columns` is a max, clamped down to fit the viewport so it never overflows on narrow/mobile screens); with `fluid` (inline only) it fills the parent width and the grid reflows to more, wider columns. The currently-selected icon is previewed above the grid — left of the filter input, or on its own row when `filterable` is `false` — tinted via `selectedIconIntent`. Controlled via `value` + `onPick`, with a restrictable `icons` set. Every sub-component is customizable through `buttonProps`, `inputProps`, `panelProps`, `iconButtonProps`, and `popoverProps`, plus the standard prop set: intent, size, flat, customTheme, tooltip, disabled, and grid layout controls (`columns`, `gridHeight`, `filterable`, `inline`, `fluid`). |
| **ReqoreInput** | Text input field with optional icons, clear button, loading states, and comprehensive styling options. Accepts an optional `radiusSize` (`TSizes`) that overrides the `size`-derived corner roundness using the pronounced `RADIUS_FROM_RADIUS_SIZE` scale. Note: the browser caps `border-radius` at half the control's height, so on a `size='normal'` input (~38px tall) a large `radiusSize` (`big` and up) visually clamps to a full pill — pick a bigger `size`, or accept the pill, rather than expecting a specific corner radius. The same height-cap applies to `ReqoreTextarea`. |

| **ReqoreLink** | Inline, themeable, keyboard-accessible text link. Renders a real `<a href>` when given `href` (so middle-click / open-in-new-tab work; `external` adds `target="_blank"` + a safe `rel`) or a `<button type="button">` when given `onClick` — the same affordance whether the link navigates or triggers an in-app action. Flows `inline` by default (`inline={false}` for an `inline-flex` row with an icon child), `underline` toggles the underline, and it supports the standard prop set: `intent` (colours the text), `size`, `customTheme`, `effect`, `tooltip`, and `disabled` (dimmed + non-interactive; drops the `href`). Use it for clickable text inside a sentence or list where `ReqoreButton` (a block control) would break the line. |

| **ReqorePanel** | Container component with optional header, footer, actions, and resizable panels with breadcrumbs support. Optional `raised` adds a subtle 3D inset highlight when paired with `flat`, suppressed whenever the panel actually draws a border — normally that means an `intent` is set, but an `accentPosition` panel draws no border, so `raised` applies there too. Optional `accentPosition` (`'left'` \| `'top'`) + `accentSize` (px or a `TSizes` name via `ACCENT_SIZE_TO_PX`; default `5` = `'normal'`) render the intent as a single edge strip instead of tinting the whole border (the border goes neutral — at rest AND on hover — or disappears on `flat` panels) — mirroring ReqoreCallout's accent API. With `stickyHeader` the wrapper stops clipping, so the strip rounds its own corners to match the panel. `stickyHeader` pins flush to the visible top edge of whatever scrolls, even when that scrollport carries its own top padding — which every default panel/drawer/modal body does, since the panel body puts `padding` and `overflow` on one element. The panel measures that padding at runtime and subtracts it from the sticky `top`; `stickyHeaderOffset` remains a deliberate caller offset applied on top of that corrected zero. Note the scroll ancestor is resolved by walking for `overflow-y: auto | scroll | overlay | hidden` — `hidden` counts, because it is a scroll container and does capture sticky. Header layout is configurable via `iconWithLabel` (default `false`; when `true`, the leading icon renders inside the label+badge row so the description sits beneath both icon and label) and `iconVerticalAlign` (`'top'` \| `'center'` \| `'bottom'` — default `'center'`; only takes effect when `iconWithLabel={false}`). Accepts an optional `radiusSize` (`TSizes`) that overrides the default `size`-derived corner roundness using the pronounced `RADIUS_FROM_RADIUS_SIZE` scale. An action declared `show: 'hover'` is hidden until the panel is hovered — but ONLY where the pointer can hover: the hiding rule sits inside a `@media (hover: hover) and (pointer: fine)` query, so on touch the action stays visible instead of being `display: none` with no route to it. |

| **ReqoreTable** | Advanced data table with sorting, filtering, column pinning, resizing, paging, and export capabilities. Filled tables measure only their flex-allocated table wrapper, so top or bottom paging controls reserve space without clipping the last rows.
